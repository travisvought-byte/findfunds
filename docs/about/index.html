About Ohio Community Events

Ohio Community Events maps the fairs, festivals, fish fries, dinners and holiday events that bring Ohio towns together, and the posts, parishes, libraries, fire departments and other groups that run them, so anyone can find them and join in.

Where listings come from

  • Public lists: the Ohio fair schedule, diocesan fish fry lists, festival calendars, and the rosters of veterans posts, libraries, park districts, chambers and visitors bureaus.
  • Organizers' own sites. A listing says whether it was checked there or only on someone else's list.
  • Anyone can send an event or a correction. We check each one before it goes up.

Every listing shows its source and the date we last checked it. Listings we haven't rechecked in six months get checked again. Most dates shown in the off-season are last year's, and the listing says so.

Money

Listings are free. We never collect or hold money for anyone. Ohio allows raffle and 50/50 tickets to be sold in person only, so we never link to online raffle ticket sales.

Privacy

We count visits with GoatCounter, which uses no cookies and doesn't store your IP address. The site is hosted on GitHub Pages, which may keep server logs for security. Contact details you send with an event are used only to check it and are never published.

Who runs it

Ohio Community Events is a free community service of Veteran Home Guardians, an Ohio 501(c)(3) that places veteran visitors in long-term care facilities.
