About FindFundraisers.org

FindFundraisers.org lists community fundraisers so people can find them, and so the groups that run them get a simple page and flyer without paying anyone.

How listings work

  • Anyone can send an event. We check each one before it goes up.
  • Some listings start from public lists, such as a diocese's fish fry page. Those say where they came from and ask you to call first until the organizer confirms them.
  • Organizers can send new dates or corrections any time from their event's page.

Money

We never collect or hold money for anyone. A page links to the group's own way to give, or says to bring cash. Ohio allows raffle and 50/50 tickets to be sold in person only, so we never link to online raffle ticket sales.

Privacy

We count visits with GoatCounter, which uses no cookies and doesn't store your IP address. The site is hosted on GitHub Pages, which may keep server logs for security. Contact details you send with an event are used only to check it and are never published.

Who runs it

FindFundraisers.org is a free community service of Veteran Home Guardians, an Ohio 501(c)(3) that places veteran visitors in long-term care facilities. It is a sister site of FindBingo.org.
